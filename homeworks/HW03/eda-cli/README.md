`eda-cli` — мини-приложение в рамках HW №3 командной строки для выполнения разведочного анализа данных (Exploratory Data Analysis, EDA) на CSV-файлах.  
Проект реализован в качестве домашнего задания **HW03** и демонстрирует:

- работу с проектом на `uv`;
- использование `src/`-layout;
- оформление EDA-логики в виде модулей;
- расширение CLI-интерфейса;
- базовое тестирование логики анализа данных.

---

Установка и подготовка окружения
Перейдите в каталог проекта:
cd homeworks/HW03/eda-cli
Установите зависимости с помощью uv:
uv sync
Использование CLI
Команда overview
Команда предназначена для быстрого просмотра базовой информации о датасете и эвристик качества данных.
uv run eda-cli overview data/example.csv
Команда:
загружает CSV-файл;
вычисляет размеры датасета;
рассчитывает эвристики качества данных;
выводит результат в стандартный вывод.
Команда report
Команда report формирует расширенный EDA-отчёт и сохраняет его в указанную директорию.
Пример базового запуска:
uv run eda-cli report data/example.csv --out-dir reports_example
Параметры команды report
Параметр	Описание
--out-dir	Каталог для сохранения отчёта и артефактов (обязательный параметр)
--max-hist-columns	Максимальное число числовых колонок для построения гистограмм
--title	Заголовок отчёта (первая строка report.md)
--min-missing-share	Порог доли пропусков для отнесения колонки к проблемным
--json-summary	Сохранить дополнительный файл summary.json
Пример расширенного запуска:
uv run eda-cli report data/example.csv \
  --out-dir reports_example \
  --title "EDA Report for Example Dataset" \
  --max-hist-columns 3 \
  --json-summary
Генерируемые артефакты
В директории, указанной в --out-dir, создаются:
report.md — Markdown-отчёт с описанием датасета и эвристик качества;
hist_<column>.png — гистограммы числовых признаков;
summary.json (опционально) — компактная JSON-сводка с основными метриками.
Эвристики качества данных
В модуле core.py реализованы следующие эвристики:
наличие пропущенных значений;
наличие константных колонок;
наличие категориальных признаков с высокой кардинальностью;
интегральный показатель качества данных quality_score.
Эвристики используются при формировании отчёта и JSON-сводки.
Тестирование
Для проверки корректности логики анализа данных используются тесты на pytest.
Запуск тестов:
uv run pytest -q
