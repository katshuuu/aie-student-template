EDA CLI 🧑🏻‍💻

Небольшая утилита командной строки для простого анализа CSV-файлов.
Используется при выполнении Домашнего задания 03 курса «Инженерия ИИ».

## Требования

- Python версии 3.11 или выше
- Установленный в системе инструмент [uv](https://docs.astral.sh/uv/)

## Инициализация проекта

Выполните команду в корневой папке проекта (HW03):

```bash
uv sync
```

Эта команда:

- создаёт виртуальное окружение `.venv`;
- устанавливает зависимости, указанные в `pyproject.toml`;
- добавляет проект `eda-cli` в текущее окружение.

## Запуск CLI

### Краткий обзор

```bash
uv run eda-cli overview data/example.csv
```

Параметры:

- `--sep` – символ-разделитель (по умолчанию `,`);
- `--encoding` – используемая кодировка файла (по умолчанию `utf-8`).

~~~bash
uv run eda-cli head data/example.csv --n 10
~~~

Параметры:

- `--sep` – символ-разделитель (по умолчанию `,`);
- `--encoding` – кодировка файла (по умолчанию `utf-8`).
- `--n` – сколько первых строк показать (по умолчанию `5`).

### Полный EDA-отчёт

```bash
uv run eda-cli report data/example.csv --out-dir reports
```

Параметры:

- `--out-dir` – папка, в которую будет сохранён отчёт;
- `--sep` – символ-разделитель (по умолчанию `,`);
- `--encoding` – кодировка файла (по умолчанию `utf-8`);
- `--max-hist-columns` – максимальное число числовых колонок для построения гистограмм (по умолчанию `6`);
- `--top-k-categories` – количество самых частых значений для категориальных колонок (по умолчанию `5`);
- `--title` – заголовок отчёта (по умолчанию `EDA-отчёт`);
- `--min-missing-share` – минимальная доля пропусков, при которой колонка считается проблемной (по умолчанию `0.05`).

После выполнения команды в каталоге `reports/` будут созданы:

- `report.md` – основной отчёт в формате Markdown;
- `summary.csv` – сводная таблица по колонкам;
- `missing.csv` – информация о пропусках;
- `correlation.csv` – матрица корреляций (если есть числовые колонки);
- `top_categories/*.csv` – top-k значений для строковых колонок;
- `hist_*.png` – гистограммы числовых признаков;
- `missing_matrix.png` – изображение с распределением пропусков;
- `correlation_heatmap.png` – тепловая карта корреляций.

Пример запуска eda-cli report с дополнительными параметрами:

```bash
uv run eda-cli report .\data\example.csv --out-dir reports_example --max-hist-columns 5 --title "Мой отчёт" --top-k-categories 4 --min-missing-share 0.052
```
